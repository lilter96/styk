# Обзор STYK

Компоновка повторяет структуру `styk-demo`: приветственный блок, показатели,
сравнение данных сервисов, круговая диаграмма, последние загрузки и проверки.
Используются существующие шрифты и цветовые переменные STYK; новых зависимостей нет.

Все значения поступают из `/api/diagnostics` для выбранного рабочего пространства
и пары аккаунтов. На вкладке обзора отчёт обновляется раз в 30 секунд, а также
при возвращении фокуса окну. Это чтение сохранённых данных: загрузка из сервисов
по-прежнему запускается в разделе интеграций.

- Карточки каталогов: `batches.ozon.counts.products` и
  `batches.moysklad.counts.products`, только при `present=true`.
- Связи складов: `mapping_counts.confirmed_warehouses`.
- Ошибки: количество проверок `FAIL`. Блок внимания содержит все проверки,
  не имеющие статуса `PASS`, включая ещё не выполненные.
- Сравнение сервисов: `products`, `warehouses` или `stock_rows` последней загрузки.
  Записи остатков не интерпретируются как единицы товара.
- Доля сопоставления: `catalog_confirmed_products / catalog_products` текущего
  каталога Ozon. Исторические связи `confirmed_products` не используются как
  покрытие текущего каталога.

Отсутствующие значения показываются как «Нет данных»; подтверждённый ноль
остаётся нулём. Исходные статусы, время загрузки, предупреждения об устаревании,
незавершённости и неизвестных остатках, детали и рабочие переходы сохранены.
Демо-выручка, прибыль, динамика продаж и список заказов не перенесены:
существующий API не предоставляет эти бизнес-показатели.

Проверки интерфейса покрывают переключение метрик, различие между неизвестным
значением и нулём, обновление отчёта, покрытие текущего каталога и переходы из
блока внимания. Схема базы данных и серверные операции не менялись.
