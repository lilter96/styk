# Дизайн-система STYK

Основа взята из локальных лендинга и демо. Общие токены находятся в `web/src/design-system.css`: основной `#693cff`, hover `#5930e8`, фокус `#1769ff`, текст `#111936`, вторичный текст `#667394`, рамка `#e9edf8`, фон `#f6f8ff`, градиент `#693cff → #9254ff`. Используется локальный Inter с кириллицей; внешние запросы шрифтов не добавлены. Поверхности белые, с тонкой рамкой и мягкой тенью. Числовые данные получают tabular figures.

Каркас `AppShell.tsx` включает боковую навигацию с SVG-иконками, breadcrumb текущего раздела, верхнюю панель с существующим выбором подключений и рабочую область. На ширине до 900 px навигация открывается в drawer через существующий `IntegrationDialog`: фокус удерживается внутри, Escape закрывает меню, фокус возвращается к кнопке. Для интерактивных элементов определён видимый фокус; есть ссылка перехода к содержимому. `prefers-reduced-motion` отключает продолжительные переходы.

## Компоненты и размеры

`UI.tsx` содержит `Icon`, `Brand`, `PageHeader`, `StatePanel` (empty/loading/error) и `ProviderBadge`. `AppShell` и внутренний `Navigation` используются всеми рабочими маршрутами. Существующие формы, таблицы, статусы и диалоги используют общие токены вместо прежних несогласованных оттенков. Native input/select/checkbox и прежний механизм диалогов сохранены; конкурирующие UI-библиотеки не добавлены.

- Заголовок страницы: 26 px, на mobile 23 px; текст: 13 px, подписи: 11–12 px.
- Кнопки и поля: минимум 38 px; важные существующие подтверждения сохраняют свои размеры и подписи.
- Радиусы: 8 / 12 / 16 px; рабочие панели: 12 px.
- Основной интервал: 4 / 8 / 12 / 16 / 20 / 24 / 32 px.
- Успех: `#087c58` на `#e8f8f1`; предупреждение: `#946000` на `#fff7e6`; ошибка: `#bd2949` на `#fff0f3`.
- Hover: 150 ms; drawer использует существующую доступную реализацию диалогов.

Таблицы имеют согласованные заголовки, строки и фокусируемые контейнеры. Список сопоставления на телефоне сохраняет существующее представление строк в виде карточек со всеми действиями. Таблицы каталога и истории прокручиваются внутри контейнеров. Переключатель плотности пока не добавлен; используется единая компактная плотность.

## Границы

Вместо создания неиспользуемых обёрток для каждого native control обновлены действующие компоненты и их стили. Отдельные абстракции MultiSelect, Toast, Tooltip и прочие из расширенного списка задания не создавались, если их сценариев нет в текущем приложении. 3D и новые библиотеки анимации не добавлены. Полный аудит доступности, память и производительность на тысячах реальных записей требуют отдельного измерения.
