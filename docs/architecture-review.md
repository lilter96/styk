# Architecture review

The monolith keeps API DTOs in connector packages, and PostgreSQL transactions atomically persist imports and confirmations. Importers use separate HTTP clients with similar retry and pagination logic; keep these separate until shared behavior is proven. Tenant ownership and operator authentication are not implemented: local administrative scopes are trusted input, not authorization. Product matching retains mappings if imports omit rows; imports are traversals, not snapshots. The worker uses leases and claim tokens, but recovery can overlap execution and is safe only for the mock operation. Real writes require unknown-outcome handling and reconciliation. Ozon's direct contract remains unverified against live API. Mapping uniqueness is scoped to a tenant and account pair; no tenant-account ownership registry exists.
